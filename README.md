# FDE Roadmap Tracker

A local, single-user web app to track progress through a personal 17-week
Forward Deployed Engineer learning-and-build roadmap. Runs entirely in the
browser — no backend, no auth, no cloud sync. State persists in
`localStorage`.

See `CLAUDE.md` for the full spec and `plan.md` for the build plan/checklist.

## Stack

React + TypeScript + Vite + Tailwind CSS.

## Development

```bash
npm install
npm run dev
```
